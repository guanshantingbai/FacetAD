# Locked evidence protocol

The unit is a frozen three-member probability ensemble. All example IDs are test queries. Selection is for illustration only. No support data, target thresholds, training, search, or new calibration.

A. Sort nonempty-mask queries by SHA256(dataset|relative ID) within class; take at most 12 per class on MVTec, VisA, DAGM. Compute exact within-image foreground vs background AUROC (ties half). Color boundary AUROC compares foreground and background within Euclidean distance 14 px of their interface. Select one highest eligible case per dataset per phenomenon, ordering ties by ID. (1) A ranks foreground at/below chance, both H and plain fusion improve: rank by fusion minus A. (2) H increases background relative rank vs A and fusion partially restores it: rank by fusion minus H, require A > fusion > H. (3) Color: rank by final minus plain fusion boundary AUROC, require positive. (4) H negative: rank by A minus H, require H and plain fusion both worse than A. Report absent eligible cases. Display negative DAGM and all three datasets. Use one fixed [0,1] probability scale. H-off column is standalone calibrated H with residual zero, without A or color. The separate final on/off test retains fusion and color.

B. Enumerate all within-category positive/negative image pairs of the core classification datasets. A strict sign reversal defines a corrected or broken example. Orthogonal recovery requires an off→on correction that orthogonal-only also corrects. Rank correct/broken by absolute change in pair probability gap; rank recovery by absolute on vs orthogonal-only pair-gap mismatch ascending. Ties by dataset, category and IDs. Main figure uses industrial examples from MVTec, VisA and DAGM if available; retain all qualifying candidates locally and audit all domains. Single-image margin changes are differences of ensemble logits. Dynamic does not change the heatmap.

Pixel error counts use 100,000 independent foreground/background pixel pairs per category drawn uniformly with replacement across all official test pixels and masks, fixed SHA-derived RNG. Reuse pairs across methods. Count ties as half; report paired Monte Carlo SE for the difference. False alarms here mean foreground/background rank reversals, not thresholded image decisions. No target-set threshold. Standalone and final H-off comparisons have different anchors.

Timing uses the first eight MVTec query IDs in official order, a fixed cyclic sequence and source VisA weights; batch 1/8, five warm-ups per configuration per round, 50 synchronized observations in each of three rounds. Core forward spans frozen encoder and score readouts. End-to-end spans file open/decode, preprocessing/H2D, forward, full heatmap processing and CPU probability outputs. Model load excluded. Stage timing uses synchronization barriers. All input-bearing figures and large candidate archives remain local pending redistribution clearance.
